Ubuntu PTP set up Boundary Clock (BC): https://wiki.gsi.de/TOS/Timing/RunOrdinaryBoundaryClocksUsingLinuxptp

commands: ptp4l, phc2sys

ptp4l: Synchronizes the NIC’s hardware clock (PHC) with connected device. PTP master is decided based on priority.
phc2sys: Synchronizes two clocks within the system; in this case, it aligns the system clock with the slave (clock from GM) NIC’s hardware clock (PHC), and other NICs together.

So ptp4l produces 1 slave and n masters for a system. Then phc2sys -a uses this information, and takes slave NIC as a source (-s), and master NICs as a sink (-c) to synchronize all PHCs together

STEPS:

1. Confirm no time synchronization on a local system


2. Perform PTP synchronization

sudo cp ./ptp4l.conf /etc/linuxptp/my-ptp4l.conf

# Without input?
sudo ptp4l -f /etc/linuxptp/my-ptp4l.conf -m 
-f: Configuration file
-m: Print messages

sudo ptp4l \
    -f /etc/linuxptp/my-ptp4l.conf \
    -i enp3s0 \
    -i enp5s0 \
    -i enp6s0 \
    -i enp7s0 \
    -i enp8s0 \
    -m


3. Synchronize NICs and System Clock together

sudo phc2sys -a -r -m
-a: Uses running ptp4l to automatically adjust sync direction 
-r: Synchronizes system clock (if used once, not possible time source)
-m: print messages


4. Check

$ sudo phc_ctl /dev/ptp0 -- get        # PTP time of the slave clock in the demo BC

$ sudo phc_ctl /dev/ptp1 -- get        # PTP time of the master clock in the demo BC
